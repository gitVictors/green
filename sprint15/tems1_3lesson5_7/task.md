Вам поступил заказ на разработку дизайна базы данных документов, удостоверяющих личность. Заказчик — компания «ПИН: полиморфизм, инкапсуляция, наследование». В базе должны быть реализованы классы для паспорта, водительских прав, международных водительских прав, набора путешественника и общий класс идентификационных документов.
Вы занялись разработкой исходя из требований и в самые короткие сроки подготовили первый вариант. Но в это же время в совете директоров случились изменения. Один из совладельцев ушёл из компании и оставил за собой права на использование слова «наследование» в названии. Теперь компания называется «ПИ: полиморфизм, инкапсуляция». Компания не хочет иметь ничего общего с предыдущим названием, поэтому просит вас избавиться от наследования в вашем коде. При этом вся функциональность должна сохраниться.
Вы предупредили заказчика, что придётся пользоваться грязными приёмами, такими как reinterpret_cast или С-style конвертация. Заказчик готов на всё, лишь бы вы решили его проблему.
Вам дан рабочий вариант программы с наследованием. Перепишите код так, чтобы программа работала также, но в ней не использовалось наследование.
# Что нужно сделать
Нужно реализовать функциональность наследования без использования наследования в коде. Пригодятся ваши знания о том, как устроены объекты.
Добавьте все нужные «виртуальные» функции и указатели на них, чтобы сохранить полиморфизм. Для этого реализуйте собственные таблицы виртуальных функций.
Из-за запрета наследования деструкторы больше не смогут быть виртуальными. Реализуйте в каждом классе метод Delete, отвечающий за разрушение объекта.
# Проверка
Заказчик проверит, что ваша программа выводит на экран то же, что выводила до запрета наследования. Часть тестов вам дали для самопроверки, а другую часть компания будет запускать в закрытом тестировании.
Отредактированные тесты для проверки кода без наследования:

```cpp
cout << "Test1"sv << endl;
Passport pass;
PrintInfo(pass);
PrintInfo(3).PrintID();

cout << "Test2"sv << endl;
array<IdentityDocument*, 3> docs = { (IdentityDocument*)(new Passport()), (IdentityDocument*)(new DrivingLicence()), (IdentityDocument*)(new Passport()) };
for (const auto* doc : docs) {
    doc->PrintID();
}

for (size_t i = 0; i < docs.size(); ++i) {
    docs[i]->Delete();
}

cout << "Test3"sv << endl;
array<IdentityDocument, 3> docs2 = {Passport(), DrivingLicence(), IdentityDocument()};

for (size_t i = 0; i < docs2.size(); ++i) {
    docs2[i].PrintID();
}

PrintInfo(docs2[0]);

cout << "Test4"sv << endl;
IdentityDocument::PrintUniqueIDCount();

cout << "Test5"sv << endl;
Passport pass2;
pass2.PrintUniqueIDCount();
```


Для корректной реализации удаления объектов, созданных через new, в переработанных тестах уже подставлен вызов метода Delete, реализацию которого вам тоже нужно написать.

Ограничения
Не используйте наследование и виртуальные методы.
Не нужно реализовывать возможность удаления объектов, созданных с помощью new [].
В коде не должно быть ключевого слова virtual.
Как будет тестироваться ваш код
Автоматические тесты проверят последовательность создания и разрушения объектов аналогично отредактированным тестам.
Наличие наследования в коде будет проверяться поиском ключевого слова virtual.
